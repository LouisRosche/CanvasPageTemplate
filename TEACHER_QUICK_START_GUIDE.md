## 🚀 Getting Started in 5 Minutes

### Step 1: Open the Template
1. Download the `universal-canvas-prototype.html` file
2. Open it in your web browser (Chrome, Firefox, Safari, Edge)
3. Click the **"⚙️ Customize This Page"** button in the top right

### Step 2: Fill in Basic Info
```
Subject: [Choose from dropdown]
Grade Level: [Select your grade]
Unit/Topic: [e.g., "Photosynthesis" or "Quadratic Functions"]
Teacher Name: [Your name]
```

### Step 3: Choose Your Structure
- ☑ Do you want an opening hook/phenomenon?
- ☑ Pre-assessment for baseline data?
- How many learning stations? (1-10)
- ☑ Exit ticket for checking understanding?

### Step 4: Select Features
- ☑ Vocabulary glossary
- ☑ Differentiation options (Foundations/Target/Extensions)
- ☑ Progress tracker for students
- ☑ Help resources

### Step 5: Save Your Work
1. Click **"Apply"** to see your changes
2. Click **"💾 Export HTML"** to save your customized page
3. Share the HTML file with students!

**That's it! You've created a custom learning page in under 5 minutes.**

## 🎨 Customization Examples by Subject

### 📘 SCIENCE EXAMPLE: Photosynthesis Lab

**Configuration:**
```yaml
Subject: Science
Grade: 7th Grade
Topic: Photosynthesis & Cellular Respiration
Structure:
  - Opening Phenomenon: "Why do plants grow faster in greenhouses?"
  - Pre-Assessment: Misconception survey
  - Station 1: Virtual lab - Light and plant growth
  - Station 2: Diagram analysis - Inside the chloroplast
  - Station 3: Design challenge - Optimize plant growth
  - Exit Ticket: Explain photosynthesis in your own words
```

**Key Components to Include:**
- 🔬 Lab safety protocols
- 📊 Data collection tables
- 🧪 Scientific method scaffold
- 📈 Graph creation tools
- 🌱 Real-world connections (agriculture, climate)

**Differentiation Strategy:**
- **🟢 Foundations**: Labeled diagrams, sentence starters, step-by-step procedure
- **🟡 Target**: Independent investigation with guiding questions
- **🔴 Extensions**: Design your own experiment, research current applications

### ➕ MATH EXAMPLE: Solving Systems of Equations

**Configuration:**
```yaml
Subject: Mathematics
Grade: 8th Grade
Topic: Systems of Linear Equations
Structure:
  - Opening Hook: "How do businesses determine break-even points?"
  - Pre-Assessment: Review slope and y-intercept
  - Station 1: Graphing method practice
  - Station 2: Substitution method
  - Station 3: Elimination method
  - Station 4: Real-world application problems
  - Exit Ticket: Choose best method and solve
```

**Key Components to Include:**
- 📐 Multiple solution strategies
- 🖼️ Visual representations (graphs, tables)
- 🧮 Step-by-step worked examples
- 💼 Real-world applications (business, engineering)
- ✅ Self-checking with answers

**Differentiation Strategy:**
- **🟢 Foundations**: Start with simpler numbers, use algebra tiles/manipulatives, graphic organizers
- **🟡 Target**: Standard problems, multiple representations required
- **🔴 Extensions**: Systems with 3 variables, non-linear systems, create your own word problems

## 🎯 Common Use Cases

### Use Case 1: Single-Day Lesson
**Time:** One class period (45-90 minutes)

**Structure:**
```
10 min - Do Now (activate prior knowledge)
30 min - Main activity (practice, investigation, or creation)
5 min  - Exit ticket (check for understanding)
```

**Template Settings:**
- Simple structure (1-2 activities)
- Focus on ONE learning target
- Quick formative assessment
- Minimal differentiation (choice within activity)

---

### Use Case 2: Multi-Day Unit
**Time:** 1-2 weeks

**Structure:**
```
Day 1: Introduction & pre-assessment
Days 2-4: Learning stations (build understanding)
Day 5: Application or project
Day 6-7: Peer review and revision
Day 8: Summative assessment & reflection
```

**Template Settings:**
- Multiple interconnected pages (link between days)
- Progressive complexity (scaffold learning)
- Multiple assessment points
- Full differentiation menu

---

### Use Case 3: Flipped Classroom
**Time:** Homework + class time

**Structure:**
```
BEFORE CLASS (home):
- Watch video lessons
- Read materials
- Complete pre-questions

IN CLASS:
- Quick review and Q&A
- Application activities (problem-solving, creation, discussion)
- Collaborative work
- Teacher provides just-in-time support
```

**Template Settings:**
- Clear separation: "Before Class" and "In Class"
- Video embeds with viewing guides
- Check your understanding questions
- In-depth application activities

---

### Use Case 4: Station Rotation Model
**Time:** One class period with rotations

**Structure:**
```
Students rotate through 4 stations (15 min each):
1. Teacher station (direct instruction, small group)
2. Technology station (simulation, research, creation)
3. Collaborative station (group work, discussion)
4. Independent station (practice, reading, reflection)
```

**Template Settings:**
- Timer included
- Clear rotation schedule
- Self-paced activities
- Progress tracking

---

### Use Case 5: Project-Based Learning (PBL)
**Time:** 2-4 weeks

**Structure:**
```
Week 1: Entry event & project launch
        Research and planning
Week 2: Creation and iteration
        Formative checkpoints
Week 3: Refinement and practice
Week 4: Presentations and reflection
```

**Template Settings:**
- Project overview with rubric
- Milestone checkpoints with deadlines
- Resource library
- Collaboration tools
- Portfolio/documentation space

## 💡 Tips & Tricks

### Design Tips

1. **Start Simple**
   - Your first version doesn't need to be perfect
   - Start with basic structure, add complexity later
   - Test with one class before rolling out widely

2. **Student-Friendly Language**
   - Use "you" language ("You will..." not "Students will...")
   - Break complex directions into numbered steps
   - Include examples of what success looks like

3. **Visual Hierarchy**
   - Use colors to organize (same color = same type of activity)
   - Icons help students scan quickly
   - White space prevents overwhelm

4. **Time Estimates**
   - Always include estimated time for each section
   - Students can plan their work session
   - Helps with time management skills

5. **Mobile-First**
   - Many students only have phones
   - Test your page on mobile before sharing
   - Keep forms and interactions simple

### Accessibility Best Practices

✅ **Use headings properly** (H1 → H2 → H3, no skipping)
✅ **Add alt text** to all images
✅ **Sufficient color contrast** (don't rely on color alone)
✅ **Keyboard navigation** (all buttons/links accessible)
✅ **Screen reader friendly** (use semantic HTML)

### Time-Saving Strategies

1. **Create a Template Library**
   - Save your favorite designs by subject/activity type
   - Reuse and adapt (don't reinvent every time)
   - Share with your department/team

2. **Collaborative Planning**
   - Share with colleagues
   - Each person creates 1-2 stations
   - Combine into complete lesson

3. **Student-Created Content**
   - Have students create vocab definitions
   - Students submit example problems
   - Student work becomes models for next year

4. **Bank of Components**
   - Keep a collection of: discussion questions, exit tickets, reflection prompts
   - Copy-paste into new lessons
   - Adapt for context

## 📤 Sharing with Students

### Method 1: Google Classroom (Recommended)
1. Save your HTML file
2. Upload to Google Classroom as "Material" or "Assignment"
3. Students click to open in browser
4. Optionally: Make it the "Topic" page for a unit

**Pros:** Integrated with their existing workflow, easy distribution
**Cons:** Requires internet access

### Method 2: Learning Management System (Canvas, Schoology, etc.)
1. Upload HTML file to Files/Resources
2. Embed in a Page or Module
3. Students access through LMS

**Pros:** Central location, tracks access
**Cons:** May require administrator permissions

### Method 3: Direct Link (Google Drive, Dropbox)
1. Upload HTML to cloud storage
2. Set sharing to "Anyone with link can view"
3. Share link with students (email, messaging app, QR code)

**Pros:** No LMS required, works anywhere
**Cons:** Students need to bookmark or save link

### Method 4: Offline Distribution
1. Save HTML file to flash drives
2. Students copy to their devices
3. Works completely offline

**Pros:** No internet required, truly accessible
**Cons:** Physical distribution needed

### Method 5: QR Code
1. Upload HTML file online
2. Generate QR code for URL
3. Post QR code in classroom
4. Students scan to access

**Pros:** Easy access, no typing URLs
**Cons:** Requires smartphone or tablet

   - What questions do you still have?

## ❓ FAQ

### Q: Do students need special software to view these pages?
**A:** No! Just a web browser (Chrome, Firefox, Safari, Edge). Works on computers, tablets, and phones.

### Q: Can students work offline?
**A:** Yes! Students can save the HTML file and open it without internet. However, embedded videos and Google Forms require internet.

### Q: How do I collect student work?
**A:** Options:
- Embedded Google Forms (auto-collects responses)
- Upload to Google Classroom
- Screenshot/photo submission
- Print and turn in paper version

### Q: Can I edit the page after sharing it?
**A:** Yes, but students will need the updated file. Best practice: finalize before sharing, or use cloud links that auto-update.

### Q: Is this compatible with screen readers?
**A:** Yes! The prototype includes proper semantic HTML and ARIA labels for accessibility.

### Q: Can students use this on phones?
**A:** Yes! The design is mobile-responsive and works on any screen size.

### Q: How do I create my own custom components?
**A:** The full version includes a component builder. For now, you can copy-paste and modify existing components in the HTML.

### Q: Can I use this for virtual/remote learning?
**A:** Absolutely! It's perfect for remote learning because everything is in one place (no clicking through multiple tabs).

### Q: Is this free?
**A:** Yes! This is open-source and free to use and modify.

### Q: Can I share my templates with other teachers?
**A:** Yes! Share the HTML file or upload to a template library (coming soon).

### Q: What about student data privacy?
**A:** The HTML page itself doesn't collect any data. If you use embedded Google Forms, Google's privacy policies apply. Always follow your district's policies.

### Q: Can I print these for students without devices?
**A:** Yes! Use your browser's Print function (Ctrl+P or Cmd+P). The page is optimized for printing.
